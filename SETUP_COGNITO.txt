SECURITY NOTES
Do not put an AeroAPI key, client secret or password in GitHub code.
Cognito login does NOT make GitHub Pages HTML private.
Check both API routes are protected before public sharing.
A separate Open Meteo forecast endpoint is called directly by the browser.
Frontend tokens are held in browser sessionStorage, which reduces persistence but
is still accessible to injected JavaScript. Avoid untrusted third-party scripts.
Tokens expire and this starter implementation requests another login rather than
silently renewing the token.
